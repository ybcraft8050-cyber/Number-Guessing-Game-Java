# 🎮 Number Guessing Game - Java Project

## 📌 Project Overview
This is a console-based Java game where the system generates a random number between 1 and 100, and the user has to guess it. The game provides hints like "Too High" or "Too Low" until the correct number is guessed.

This project demonstrates Java fundamentals like loops, conditionals, user input handling, and random number generation.

---

## ✨ Features
- Random number generation (1–100)
- User input using Scanner class
- Feedback system (Too High / Too Low / Correct Guess)
- Limited attempts per round
- Score system based on performance
- Multiple rounds (Replay option)
- Console-based interactive gameplay

---

## 🛠 Technologies Used
- Java (Core Programming)
- Random class (java.util.Random)
- Scanner class (java.util.Scanner)
- Loops (while loop)
- Conditional statements (if-else, switch case)

---

## 🎯 How the Game Works
- System generates a random number
- User enters guesses
- Program gives hints:
  - 📉 Too High
  - 📈 Too Low
- User continues until correct guess or attempts end
- Score is calculated based on attempts
- User can play again

---

## 🚀 How to Run

### 1. Compile the program
javac NumberGame.java

### 2. Run the program
java NumberGame
